# Manual upload bundle

This folder mirrors the exact paths these files need to land at in the repo
(`matheusacorsi/Corteva-MAC-apps`, branch `weather-app`). Drag this folder's
contents into GitHub's "Add file → Upload files" page, keeping the same
subfolder structure (`.github/workflows/`, `scripts/`, `data/`, `INMET/`).

Delete this `_github_upload` folder itself when you're done — it's not part
of the app, just a staging area, and it's already excluded from git via
`.gitignore`.

## Files to delete manually on GitHub (upload can't remove these)

GitHub's drag-and-drop upload only adds/replaces files with matching names —
it will **not** remove old files for you. After uploading, go delete these
two directly in the GitHub UI (they're replaced by the `.parquet` files
above):

- `INMET/2025.zip`
- `INMET/2026.zip`

## Not included on purpose

- `inmet_manifest.json` — auto-generated by the workflow on its next run, no
  need to seed it manually.

## What these changes do (for reference)

- Shrinks the INMET dataset from ~140MB (raw zips) to ~27MB (compact Parquet,
  only the 5 columns the app actually uses) and stops it from growing every
  month.
- Replaces `timezonefinder` (63MB dependency) with a small bundled
  Americas-only timezone lookup (~0.3MB) using `shapely`.
- Adds comma-decimal-separator support and two new GMS coordinate formats.
- Fixes ARM Excel output to use real numeric cells (so Excel shows the
  right decimal separator automatically for whoever opens it) instead of
  fixed `.`-formatted text.
- Adds a satellite map preview next to the coordinate inputs
  (`folium`/`streamlit-folium`).
- Fixes the rainfall filter not applying to NASA-POWER-gap-filled days in
  mixed INMET/NASA output.
- Fixes "Auto" source selection discarding an otherwise-good INMET station
  just because one variable (e.g. wind direction) was fully missing for the
  period — it now gap-fills that one variable instead of abandoning the
  station entirely.
- Widens the monthly INMET auto-download window from the 1st-3rd to the
  1st-10th of the month (still checked once a day), since INMET has
  published as late as the 9th.
